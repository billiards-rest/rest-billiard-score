記録の共有

管理者

試合の記録はすべて自動で残ります。記録を消す・終わった試合を「Back」で戻す・台の固定や解除には、管理者の暗証番号が必要です。台の固定にも同じ暗証番号を使います。

読み上げ（英語）

この端末（ブラウザ）には英語の読み上げ用の声が入っていません。このままだと日本語の声で読むか、音が出ない場合があります。
・iPad / iPhone：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語 →「Samantha」などをダウンロード
・Android：設定 → 言語と入力 → テキスト読み上げ → Google音声サービスで英語（米国）の音声をダウンロード
・Windows：設定 → 時刻と言語 → 言語と地域 →「英語（米国）」を追加して音声合成を入れる、または Chrome / Edge でアプリを開く
入れたあと、このページを開き直すと一覧に出てきます。

メールアプリで開く

「表をコピー」を押してから、Gmailなどの本文に貼り付けると、この表がそのまま入ります。中止した試合は入りません。

試合履歴

お店の試合記録です（共有につながっている端末どうしで1つにまとまります）。選手名をタップするとその選手の通算が見られます。試合の記録はすべて残り、消すときは各記録の「消す」を押して、管理者の暗証番号を入れてください。

選手を選ぶ

持ち点の多い順です。苗字の頭から1文字ずつ入れると絞り込めます（ひらがなで探すには「選手」タブで、よみを登録してください）。一覧にいない選手も「選手」タブで登録できます。

HR＝1イニングの最高連続得点、BG（ベストゲーム）＝1試合のアベレージの最高。日付はその記録が出た日です。中止した試合は入りません。

持ち点

この試合だけの持ち点です。登録している持ち点は「選手」タブで変えられます。
